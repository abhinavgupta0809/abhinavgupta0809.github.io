More detail

Plain-English questions about statements, invoices, pay stubs and 1099s; the data never leaves your computer. Scope by decision: no bank linking, no advice, synthetic data only. Built with AI coding tools in weekly syncs with the co-founder. Cent Capital now owns the code, open-sourced under Apache-2.0, and credits me as the original author.

I set the bar before changing anything, and retrieval quality (MRR) rose from 0.50 to 0.79

An 80-question test set with the expected source for each answer, and a regression check that fails the build if search quality drops.

More detail

An AI judge checked against 20 of my own labels (a small check, weak evidence on its own). Every result is tied to the exact code, settings and test set that produced it.

I rejected my own changes when they missed the bar

Six local models, a new prompt and a citation checker each ran against gates set in advance. Only the model already in use held.

It blocked 6 of 6 planted data leaks, and I stated what it can't prove yet

Measured, reproducible numbers. Not a claim that it is production-ready.
